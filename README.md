## 🎮 About the Game

Fell & Sell was released on August 26, 2026, by Art Games Studio S.A. It is a single-player first-person mod-and-slash roguelike combined with shop management, crafting, exploration, and fantasy economy simulation.

---

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Fell &amp; Sell**. This trainer enhances the core expedition and merchant gameplay loop. It provides control over player survivability, combat power, movement, inventory resources, dungeon rewards, crafting materials, and shop finances while preserving the game's focus on exploring dungeons, collecting loot, upgrading equipment, and running a profitable store.

**Target Audience:** Players who want a more relaxed single-player experience, faster dungeon runs, easier crafting, protected expedition rewards, or accelerated shop development.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

2. Wait for the confirmation message *"Framework successfully installed"*.

### Step 6: Launch the Game

1. Launch the game through the Setup launcher (click **"Play"**) or via the standard shortcut.
2. In-game, press the configured hotkey to open the main control menu.

## 📖 Detailed Feature Guide

### Movement & Exploration

Enter an expedition before enabling movement-related options. Increased movement speed is useful for navigating dungeon routes, reaching deeper areas, gathering resources in the forest, and escaping dangerous encounters.

### Tools & Inventory

Use inventory options after collecting items or opening the inventory screen. They are intended for managing dungeon loot, forest resources, crafting components, weapons, armor, and goods prepared for shop shelves.

### World & Environment

Fell & Sell alternates between dangerous expeditions and merchant management. Explore descending dungeons for increasingly valuable loot, forage in the forest, return safely to the cabin, craft equipment, complete quest-board objectives, and improve the shop with fixtures and decorations.

### Combat & Weapons

Combat is built around fast first-person mod-and-slash encounters against skeletons, goblins, monstrous enemies, necromancers, and bosses. Activate health protection before difficult fights, then use damage options to shorten encounters and reach deeper dungeon areas.
